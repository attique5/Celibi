# Celibi

**Celebrate Every Special Moment.**

Celibi is a modern and beautifully designed Android application that helps you remember birthdays, anniversaries, engagements, and other meaningful occasions. With an elegant interface and convenient reminders, Celibi keeps your special moments organized in one place.

## Key Features

- Birthday reminders.
- Wedding anniversary reminders.
- Engagement reminders.
- Custom event creation.
- Upcoming event countdowns.
- Reminder notifications.
- Personalized event management.
- Beautiful, soft, and elegant color theme.
- Clean and intuitive user interface.
- Lightweight application design.

## Supported Occasions

- Birthdays
- Wedding Anniversaries
- Engagements
- Family Celebrations
- Special Occasions
- Custom Events

## Download & Installation

1. Download `Celibi.apk` from the Releases section.
2. Open the downloaded APK file.
3. Allow installation from unknown sources if prompted.
4. Install and launch Celibi.
